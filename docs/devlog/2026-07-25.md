- `src/generation/rag_pipeline.py` — 3 处调用全部更新

**验证**：编写 `diagnose_api.py` 诊断脚本，逐一测试网络连通性、简单 Chat、带 tools Chat、账户余额，定位问题后删除。

## 五、API 调用追踪系统

### 新增 `src/utils/tracker.py`

完整的 LLM 调用追踪基础设施：

- `CallTracker` 类 — 记录每次调用的模型、Token 数、耗时、费用
- `get_tracker()` 单例 — 跨模块共享
- `track(source, model)` 上下文管理器 — 自动提取 OpenAI response 的 usage 信息
- `print_summary()` — 按来源分组打印调用次数/Token/耗时/费用
- `to_dict()` — 导出结构化数据
- 持久化到 `data/api_calls.jsonl`

### 集成位置

| 文件 | 追踪点 | 来源标签 |
|------|--------|---------|
| `src/agent/react_agent.py` | ReAct 循环 LLM 调用 | `react_agent` |
| `src/agent/react_agent.py` | 最终强制回答 | `react_agent_final` |
| `src/generation/rag_pipeline.py` | 闲聊回复 | `rag_chat` |
| `src/generation/rag_pipeline.py` | 知识库外兜底 | `rag_fallback` |
| `src/generation/rag_pipeline.py` | RAG 知识回答 | `rag_knowledge` |
