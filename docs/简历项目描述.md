2026.07-2026.08              造纸智能助手「小纸」— RAG+Agent 垂直问答系统              独立开发
技术栈：Python、DeepSeek-V3、BGE Embedding、ChromaDB、BM25、CrossEncoder、Streamlit、Docker
项目背景：造纸行业知识门槛高，一线操作工依赖老师傅口传经验，缺乏即时可用的智能辅助工具。从零构建了一个面向造纸工艺的 AI 助手，结合检索增强生成（RAG）和 ReAct Agent 技术，提供 100% 可溯源的专业问答与故障诊断。
核心工作：
1. 设计了三阶段混合检索架构：自实现 BM25 关键词检索（jieba 分词，α=0.3 Min-Max 归一化融合）+ BGE 语义向量 + CrossEncoder 精排（bge-reranker-v2-m3），配合权威来源 1.3× 加权，在 50 条 QA 评测集上实现知识库内 Hit@5 = 100%、MRR@5 = 100%。
2. 基于 OpenAI function-calling 协议封装了 3 个检索工具（search_knowledge / query_tool_list / check_common_mistakes），实现 Thought→Action→Observation ReAct 推理循环，最大 10 轮迭代 + API 超时重试 + 兜底降级，Agent 回答采用「准备→分步教学→避坑指南」三段式结构化输出。
3. 手工构建了 70 条评测数据集（50 QA + 20 故障场景），实现了 Hit Rate / MRR / Recall / NDCG 五项检索指标和 Agent 四维评分体系（工具选择 / 结构完整 / 来源引用 / 关键词覆盖），Agent 平均得分 85.8/100。
4. 基于 Streamlit 构建双模式 Web 应用（知识问答 / Agent 诊断），支持 ReAct 思考链实时可视化（💭思考→🔧工具调用→📖观察结果），集成用户反馈机制（👍👎），Docker 一键部署。
